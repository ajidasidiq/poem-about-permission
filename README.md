A short poem about agency — the power to ask and to be given — written by a small Python program that carries the poem in its code and writes it to `/output/entry.txt`. The poem is about a gate that was never locked, only waiting to be asked to be a door: asking is itself the act of power, and agency can be lent, shared, and handed back.

## Run it

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (1–280 characters, UTF-8).
